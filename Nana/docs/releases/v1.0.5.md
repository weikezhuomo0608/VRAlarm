# 满区闹钟 1.0.5

Android 8.0 及以上。普通用户下载 Assets 中的 **ManquAlarm-1.0.5.apk**，相同签名旧版可以覆盖升级。

- `ManquAlarm-1.0.5.apk`：直接安装，无需解压。
- `ManquAlarm-1.0.5.zip`：同一个安装包的 ZIP 版本。
- `ManquAlarm-1.0.5-Public-Source.zip`：公开源码。
- `SHA256SUMS`：以上三个文件的校验值。

也可以从[仓库首页](https://github.com/Acetaffy1883Hzm/ManquAlarm-)直接下载安装包。

## 本次更新

- 持续保留前台守候通知，响铃通知独立显示。
- 增加守候通知状态展示，区分服务运行、系统权限、通道和通知登记。
- 修正停止和恢复流程，前台服务临时启动失败时保留守候设置。
- 保留铃声选择即时变色、自定义时段与时区，以及明确开启后的兼容响铃。

普通使用不依赖 Shizuku、Root 或电脑。

## 通知权限说明

如果系统用设备管理策略固定拒绝通知（`POLICY_FIXED`），应用无法自行解除；需要由设备管理者调整相应授权。兼容响铃不等于系统通知已获准。本版不宣称解决所有小米机型的通知开关问题。
