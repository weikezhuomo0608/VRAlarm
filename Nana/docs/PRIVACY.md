# 数据与导出说明

满区闹钟没有应用账号、广告或内置分析上报服务。后台检测直接通过 HTTPS 访问 B 站公开直播接口；服务端会收到这类网络请求通常包含的 IP 地址、请求头和目标直播间参数。

添加主播时，应用会通过同一类公开接口读取该直播间的主播名称与头像地址，并在添加时下载一次头像存入本机。此后界面显示的是这份本地缓存，不会在浏览列表时反复向外网请求图片。头像下载同样会让对方服务收到上述常规请求信息。

使用「从置顶动态获取」时，应用会请求 B 站免登录动态接口，读取你在“主播”页添加的主播的公开置顶动态文字（或你粘贴的公开动态链接对应的文字），仅用于周表识别；该接口由 B 站风控策略控制，可能随时失效。周表条目、来源文字与上传的周表图片都保存在本机应用空间，删除主播时一并清除。

使用「AI 识别图片安排」时，该张周表图片会经压缩后上传到你配置的 AI 服务商（默认 DeepSeek）处理，识别结果由你确认后才保存；除该张图片与固定的识别提示词外，应用不发送任何其他数据。此功能默认开启但只在主动点按时才发生上传，可在设置中随时关闭。AI 接口密钥仅保存在本机应用空间。

应用设置、主播列表、导入的铃声、缓存的头像和近期检测记录保存在本机应用空间。应用会记录直播状态、检测结果、错误与相关时间，便于判断提醒为什么发生或未发生。外部链接通过系统应用打开，其数据处理由对应应用或网站决定。

## 无障碍辅助

用户须在系统中主动开启。辅助服务只接收本应用的相关窗口事件，不读取窗口树、其他应用页面、屏幕内容，不执行点击、手势、按键或截图。它仅在应用内已开启守候时尝试恢复意外中断的服务。

## 用户主动导出

- 设置备份：包含配置、主播列表（名称、UID 与直播间号码）与相关诊断信息，保存到用户选定位置。不包含已缓存的头像文件本身。
- 通知诊断：包含本应用的通知状态、检查时间、系统版本、指定系统权限组件的版本等信息。
- 可选的“包含权限组件”：在用户单独选择后，尝试复制指定且可读取的系统权限组件 APK；不复制这些组件的内部应用数据。

导出文件不会由应用自动上传或发送。选择分享后，由用户自行决定接收方。手机型号、系统构建信息、配置和检查时间可能包含使用者不希望公开的内容。

公开反馈优先提供复现步骤、应用版本及必要状态截图。不要直接在公开 Issue 附上完整系统日志、设备管理策略导出、私人设置备份或系统组件 APK。开发排查需要更多内容时，应先确认具体范围并删除无关个人信息。

本仓库不附带任何测试者的原始诊断包、设备管理导出、账户凭据或发行签名私钥。
