# VR闹钟 使用指南：把权限设置对

> 闹钟响不响，权限说了算。应用装好后花 5 分钟，按下面的顺序点一遍。
> 应用里的「守候」页和「设置 → 权限检查」都有现成的入口，点一下就能跳到对应的系统设置页，不用自己找。

## 第 1 步：允许通知（最重要）

- **在哪里开**：应用「设置 → 权限检查 → 允许通知」，点按直达系统通知设置。
- **没有它会怎样**：全部白搭——应用无法弹出任何提醒，响铃也可能被系统拦下。
- **怎么算设置好**：系统里该应用的「通知」开关打开，且不要勾选任何"静默通知"之类的降级选项。

## 第 2 步：允许全屏与锁屏显示

- **在哪里开**：「设置 → 权限检查 → 全屏提醒」。
- **没有它会怎样**：锁屏时不会弹出全屏响铃页面，只能靠通知和声音。
- **怎么算设置好**：系统里「显示在其他应用上层 / 全屏通知 / 锁屏显示」处于允许状态（不同手机叫法不同）。

## 第 3 步：允许精确闹钟

- **在哪里开**：「设置 → 权限检查 → 精确闹钟」。
- **没有它会怎样**：时段切换、稍后提醒、锁屏测试这些定时动作可能晚几分钟才触发。
- **怎么算设置好**：系统里「闹钟和提醒 / 闹钟（Alarms & reminders）」允许。

## 第 4 步：电池不限制

- **在哪里开**：「设置 → 权限检查 → 后台电池权限」，或系统「设置 → 应用 → VR闹钟 → 电池」。
- **没有它会怎样**：手机一息屏，系统就可能冻结应用、推迟检测，提醒延迟从几分钟到几小时不等。
- **怎么算设置好**：电池策略选「不受限制 / 无限制」，不要选"优化"。

## 第 5 步：允许自启动（按品牌找入口）

| 品牌 | 路径 |
| --- | --- |
| 荣耀 / 华为 | 设置 → 应用和服务 → 应用启动管理 → 找到 VR闹钟 → 关闭"自动管理" → 勾选：允许自启动、允许关联启动、允许后台活动 |
| 小米 / Redmi（澎湃 OS） | 设置 → 应用设置 → 应用管理 → VR闹钟 → 自启动；同时把省电策略改为"无限制" |
| OPPO / 一加（ColorOS） | 设置 → 应用 → 应用管理 → VR闹钟 → 耗电管理 → 允许自启动、允许完全后台行为 |
| vivo（OriginOS） | 设置 → 应用与权限 → 应用管理 → VR闹钟 → 权限 → 允许自启动、后台弹出界面 |
| 三星 / 原生 Android | 一般无需额外设置，保持电池不限制即可 |

- **没有它会怎样**：应用被系统杀掉后**没有任何办法自己活过来**，守候直接静默失效。

## 第 6 步：在最近任务里锁定

- **怎么做**：打开最近任务（多任务界面），长按 VR闹钟 的卡片，选「锁定」（锁形图标）。
- **没有它会怎样**：从最近任务划掉应用 = 系统级强杀，闹钟、权限、恢复机制一起失效，**任何应用都无法自救**，只能靠第 5 步的自启动重新拉起。

## 强烈建议：两个加分项

1. **无障碍守候辅助**（可选，恢复最快的一条路）：「设置 → 后台守候 → 开启无障碍守候辅助」。它在服务意外中断时尝试自动恢复；不读屏幕、不点按钮、不截屏，只看本应用自己的状态。主动停止守候后它不会把应用拉起来。
2. **锁屏与响铃测试**：「设置 → 锁屏与响铃测试」。把音量调好，锁一次屏，确认锁屏时能弹出页面、铃声能响。这个测试用的是和正式提醒完全相同的通道。

## 可选功能

- **AI 识别周表图片**：在「设置 → AI 图片识别」填入你自己的 DeepSeek 兼容密钥（应用不内置任何密钥）。只有你主动点按时，那一张图片才会压缩上传给你填的服务商；不填密钥该功能不工作。
- **悬浮关闭按钮**：响铃时在其他应用上方显示关闭按钮，防止响铃时找不到手机。在「设置 → 小米与通知兼容」开启。

## 还是不响？三步排错

1. **通知栏里有没有 VR闹钟 的常驻守候通知**？没有 → 守候没开或被系统杀了，回应用重新开启。
2. **守候通知 / 小组件上的"最近检测"是不是刚刚**？停在几分钟前 → 检测被系统冻结了，回头检查第 4、5、6 步。
3. **打开「记录」页**：有"守候曾被中断""暂时无法确认直播状态"等条目 → 按条目里的提示处理；如果记录里什么都没有但也不响，做一次第 6 步的锁屏测试。

> 一句话总结：**通知、全屏、精确闹钟、电池不限制、自启动、锁定最近任务**——六项全绿，然后做一次锁屏测试，就可以安心守候了。

> 提醒一下：本应用本质是 AI 拼好钟，处于试运行阶段，切勿盲目信任。重要场次建议自己留个心眼，或另设一个备用闹钟。
