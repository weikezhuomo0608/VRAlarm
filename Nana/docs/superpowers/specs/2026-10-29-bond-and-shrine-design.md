# 七七闹钟 · 契约等级与神社群像（1.1.3）

日期：2026-10-29　状态：已实现　依赖：1.1.2 的 `Voice` 文案层

## C · 契约等级

### 数据来源（不新增采集）

全部从已有的本地记录算：`stats.<anchorId>` 每条 `{s,e}`（开播与下播时间，最多 60 条/主播）。

- 亲密度点数 = 场次 × 40 + 累计分钟数（未结束的本场按“到现在”计，与 `statSummary` 原有口径一致）
- 负数输入一律归零，不做补偿

### 等级表（`Bond.java`）

| 级 | 称号 | 门槛点数 |
| --- | --- | --- |
| 1 | 初见 | 0 |
| 2 | 边苔桑 | 200 |
| 3 | 常连 | 600 |
| 4 | 御守 | 1500 |
| 5 | 神社打杂 | 3000 |
| 6 | 小马娘同盟 | 6000 |

“边苔桑”取自 FF 的实际勋章名，其余称号取自她的签名（神社打杂 / 小马娘）。

### 展示

主播卡片在“上次检测”那一行下面新增一枚印章（称号）+ 一行 `亲密度 348 · Lv.2 · 距 常连 还需 252` + 进度条。桥接字段：`sessions / minutes / bondLevel / bondTitle / bondPoints / bondPercent / bondNext / bondRemain`。没有记录时不渲染，避免新装的空卡片多一行装饰。

## D · 神社群像

### 开关

设置 →「主题与外观」新增「外观风格」：`默认（清爽）` / `神社`，存 `config.skin`，`Prefs.update` 白名单校验 `default|shrine`；`applyTheme()` 切 `body.skin-shrine`。

### 视觉（纯 CSS，无新素材，且不改主色与排版）

- 卡片顶部一道朱红的“鸟居横木”：两端下折成门形，明暗主题各有配色
- 分区标题前一枚朱红双横符号
- 24 小时时间轴换成绘马底色，活动条改朱红
- 常驻通知守候卡改成御守形：上窄下宽圆角 + 顶部小结

主色仍由用户的主题色决定，神社风格只加装饰，所以能和任意配色、明暗主题共存。

## 取舍

- 不新增“观看时长”：本应用只知道自己检测到的开播区间，不宣称知道你真的在看。
- 等级只在本地算，不上传、不跨设备同步；清空记录即清零。
- 神社风格不做全局换肤（不改主色、不改圆角体系），避免和用户已选的主题色打架。
