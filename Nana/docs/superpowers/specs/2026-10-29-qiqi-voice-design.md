# 七七闹钟 · 人格化文案与开播分型（1.1.2）

日期：2026-10-29　状态：已实现　范围：文案与展示层

## 1. 目标

让七七闹钟在“开播那一声”上和原项目 VR闹钟区分开：同一套检测内核，说法换成人格化的，并按直播间标题区分场次类型。不改进播判定、响铃链路、闹钟编号与守候策略。

## 2. 语气边界（克制）

- 出现角色口吻的位置只有三处：开播提醒（通知标题、悬浮窗、锁屏响铃页）、下播小结、记录页空状态。
- 守候常驻通知、权限说明、设置项描述、诊断导出**一律保持原文案**，不加口吻。
- 语癖 `のだ` 只进“上线了のだ / 收工了のだ”这两句。

## 3. 开播分型

`Voice.kindOf(title)` 只看直播间标题，按下表顺序命中即返回（先命中先赢）：

| 顺序 | 类型 | 关键词 |
| --- | --- | --- |
| 1 | 歌回 | 歌回、歌杂、歌枠、唱、歌 |
| 2 | 联动 | 联动、连麦、联合、合作 |
| 3 | 马 | 小马、马娘、赛马、ウマ、马 |
| 4 | 游戏 | 游戏、game（忽略大小写） |
| 5 | 杂谈 | 杂谈、闲聊、杂 |
| 6 | 直播 | 其余与空标题 |

顺序的意义：`【午间】小马歌杂` 同时命中“歌”和“杂”，必须判成歌回。

## 4. 文案表

| 事件 | 之前 | 现在 |
| --- | --- | --- |
| 开播通知标题 | `辉月七七official 开播了！` | `辉月七七 上线了のだ · 歌回`（无类型时省略“· …”） |
| 悬浮窗标题 | `七七闹钟 · 辉月七七official开播了` | `七七闹钟 · 辉月七七 上线了のだ · 歌回` |
| 锁屏响铃页主标题 | `辉月七七official 开播啦。` | 同上（Java 算好经 `alarmHeadline` 下发；缺字段时回退旧文案） |
| 下播通知 | `直播已结束` / `某主播 下播了` | `收工了のだ` / `辉月七七 收工了のだ · 本场 2 小时 13 分` |
| 记录条目正文 | 直播标题原文 | `【歌回】` + 标题原文（未分类不加前缀） |
| 记录页空状态 | 故事还没开始 | 还没开演过のだ |

主播名一律先经 `Voice.shortName` 去掉 official 后缀；多主播场景显示“辉月七七”而非固定的“七七”，避免认错人。

## 5. 实现

- 新增纯 Java 内核 `Voice`（无 Android API）：`kindOf / shortName / alarmHeadline / tag / duration / endText`。
- `GuardianService`：`beginAlarm` 一次性算好并写入 `alarmHeadline`；`alarmNotification` 与 `endNotice` 只读它；`ring` 的两条记录加类型前缀。
- `MainActivity` 的状态桥新增 `alarmHeadline`，响铃页不再自己拼文案。
- `AlarmOverlay` 用同一个 `Voice.alarmHeadline`。

## 6. 验收

- `python tools/test_core.py`：11 套断言全绿，其中新增 `VoiceTests` 26 条（优先级、空标题、null、后缀剥离、时长边界）。
- `node tests/ui-regressions.cjs`：91 场景全过（旧文案断言走回退路径仍然成立）。
- `aapt2 dump badging`：`versionCode 4 / versionName 1.1.2`、label `七七闹钟`。

## 7. 已知取舍

- 分型只读标题，标题写“画画中”这类词就退回“直播”，不做猜测。
- 不做图标差异化（原生悬浮窗与通知只能用文字），类型以文字标签呈现。
- 记录页的类型标签靠写入时的前缀，不改记录结构，老记录保持原样。
